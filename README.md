# ShopSphere SDET Framework

## Tech Stack

- Playwright
- TypeScript
- Artillery
- GitHub Actions
- Docker

## Run UI Tests

```bash
npm run test
```

## Run API Tests

```bash
npm run test:api
```

## Run Load Test

```bash
npm run load
```

## Project Features

- UI Automation with Playwright
- REST API Testing
- Dynamic User Creation
- Page Object Model
- HTML Reporting
- TypeScript Framework
